## What is new

- Add Telegram sticker-pack links as independent import tasks. Keep adding links while multiple packs are fetched, downloaded and converted.
- Choose **1–6 shared import threads** in Settings; the default is **2**. Your preference is saved. Animated conversions also respect available memory.
- Follow each task separately, cancel or retry it, and clear finished task records while keeping the imported packs in your library.
- Preserve tasks when the activity is recreated. Each task owns its cache, so cancelling one task leaves other tasks intact.
- Preserve sticker order, custom pack names and authors when importing a source again, and increment the image version.

**Android 7.0 or later.** Most current phones use **arm64-v8a**; choose **universal** if unsure. These signed release APKs use the same application ID and signing certificate as the previous release. Install over the existing app to retain your library and settings.

## 中文

- Telegram 链接可添加为独立导入任务，拉取、下载和转换期间可继续添加其他贴纸包链接，支持多个包并行处理。
- 设置页新增 **导入线程数**，支持 **1–6**，默认 **2**，选择会保存。所有任务共用线程额度，动态转换另按可用内存控制并发。
- 每项任务单独显示进度，支持取消、重试和清除已结束记录；清除记录后，已导入的贴纸包仍保留在库中。
- 页面重建保留应用进程内的任务；任务使用独立缓存，取消一项不会删除其他任务的文件。
- 同源再次导入保留贴纸顺序、自定义名称和作者，并递增图片版本。

支持 **Android 7.0 及以上**。多数手机选择 **arm64-v8a**，不确定时选择 **universal**。正式安装包沿用上一版的应用 ID 与签名，可直接覆盖安装，保留贴纸库和设置。
